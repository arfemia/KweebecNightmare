# command/ - the /kweebec round-entry command

Router for `command/`. The first of the designed-for entry triggers (the void-rift pad / shrine block / guide NPC route through the same [`../round/RoundService`](../round/RoundService.java) entry and land later).

- **[`KweebecCommand`](KweebecCommand.java)** is `/kweebec [start|clash|domination|exit|endall|give|score|leaderboard|party|clashhost] [preset]` (alias `/kn`; a bare `/kweebec` runs `start`): `start` QUEUES the caller through [`../lobby/KweebecLobby`](../lobby/KweebecLobby.java)`.join` and leaves them on a live `PlayModePage` roster (it does NOT gather the world), `clash` / `domination` are the direct PvP starts that DO seat every eligible player in the caller's current world at once and launch immediately (testing/admin), `exit` leaves your queue first and otherwise your live round, `endall` force-ends every live round (admin/testing), and `give` / `score` / `leaderboard` / `party` / `clashhost` are the Moonbloom-charge, own-score, board-page, party-screen and PvP-host-NPC helpers. Preset = any loaded `RoundPresetAsset` id (the jar ships amateur, blitz, endless, hardcore, nightmare, pitch, swarm; a pack can add more), validated against `PresetConfig.getInstance().byId`, defaulting to `PresetConfig.DEFAULT` (nightmare).
- **Every user-facing string + the command/arg descriptions resolve through [`../i18n/Lang`](../i18n/Lang.java)** (the engine resolves the `super(name, descKey)` + `withOptionalArg(name, descKey, ...)` strings as lang keys, not literals). Permission scope is set with `setPermissionGroups("hytale:Adventurer")` (the non-deprecated form; the old `setPermissionGroup(GameMode.Adventure)` sugar is removal-marked and just mapped Adventure -> that group).

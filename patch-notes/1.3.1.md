Kweebec Nightmare adds eight languages, and the `/kweebec` commands take plain words: `/kweebec leaderboard`, `/kweebec start hardcore`.

Built for Update 7, and needs Ziggfreed's CommonLib 2.3.0 or newer and Perfect Utils.

### New

- Added German, Spanish, French, Hungarian, Italian, Brazilian Portuguese, Russian and Turkish. Every screen, notice and conversation in Kweebec Nightmare reads in the language your game is set to.

### Changes

- With CommonLib 2.4.0 or newer, the party screen updates on its own when someone joins, leaves or is removed, an invite arrives or runs out, or the party is disbanded.

### Fixes

- `/kweebec leaderboard`, `/kweebec score`, `/kweebec party` and `/kweebec exit` work as you type them, and `/kweebec start <preset>` queues you on that preset, such as `/kweebec start amateur`. They only worked written as `/kweebec --sub=leaderboard` or `--preset=amateur`. A plain `/kweebec` or `/kweebec start` still queues you on Nightmare.
- With CommonLib 2.4.0 or newer, the party screen shows how many are in your party, such as "1/4", where it showed "{0}/{1}".
- With Perfect Utils 1.3.1 or newer, a thrown Moonbloom no longer loses its stun on the hunter while players are in another world on the server.

### For server owners

- A server running MMO Skill Tree beside Kweebec Nightmare no longer reports the Grove Keeper as a quest giver with no quests when it starts.
- Each `/kweebec` command a player can use has its own permission node under the command's, such as `ziggfreed.kweebecnightmare.command.kweebec.start`, and every player has them by default. The admin commands need `kweebecnightmare.admin`, which operators have.

### Migration notes

- The old `/kweebec --sub=` and `--preset=` forms are gone. A script or anything else that still runs them needs the plain form, such as `/kweebec leaderboard` or `/kweebec start amateur`.
- If you grant permission nodes by hand, each `/kweebec` command a player uses now checks its own node. Grant `ziggfreed.kweebecnightmare.command.kweebec.*` to keep them all open.

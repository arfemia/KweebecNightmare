A rebuild against a much larger Ziggfreed's CommonLib, with a dialogue-loading fix that rides
along with it. No gameplay change.

- **Rebuilt against the current Ziggfreed's CommonLib.** This build compiles and runs against the
  common library's latest dialogue, loot, and leaderboard engines; the shrine, guide, and reward
  content are unaffected.
- **Fixes the guide's dialogue occasionally failing to load.** The guide NPC's conversation
  vocabulary now registers at startup instead of on first use, closing a race that could make a
  freshly booted server skip the dialogue.
- **One-time reset on upgrade: pending claimed rewards and the leaderboard.** Installing this
  version resets any reward still waiting to be claimed and the recorded high scores, both back to
  empty. Nothing else on your server is affected, and scores start accumulating again immediately.
- **Announces round wins to the shared progression system.** Kweebec Nightmare now announces a
  finished round on the shared Ziggfreed's CommonLib event bus, so any mod on that shared
  progression engine, not just an installed MMO Skill Tree, can offer a quest or achievement that
  counts finishing (or winning) a Kweebec Nightmare round, by preset.
- **The Grove Warden stays away from a server that also runs MMO Skill Tree.** On a server with
  both mods, the MMO's own guide is already standing at spawn, so the Warden no longer turns up
  beside them. Place one wherever you like with the server's own NPC spawn tooling; pressing F on
  it opens the same backstory and preset launcher it always has. On a server without MMO Skill
  Tree nothing changes: the Warden is at spawn as before.
- **The Warden is harder to lose.** Their chunk is held in memory so players can always find them,
  anything that removes them puts them back, and their health is raised past anything that can be
  dealt.
- **Two settings files are retired: `guide.json` and `guide-placements.json`.** Where the Warden
  stands is authored as an asset now, at
  `Server/ZiggfreedCommon/NpcPlacements/Kweebec_Grove_Warden.json`, and the switch to stop them
  appearing is `mods/ziggfreedcommon/npc-placements.json`. Both old files are renamed aside rather
  than deleted, with one startup message saying so, and none of their values are carried over - if
  you had moved the Warden or changed which worlds they appear in, set that up again in the asset.
  A Warden already standing in your world is left exactly where it is.
- **`/kweebec spawnguide` is removed.** Use your server's NPC spawn tooling to place a Warden by
  hand. `/kweebec clashhost` still works and now says the Duelmaster's name rather than the
  Warden's.
- **No change to the round itself.** Relighting the shrines, the hunters, the Warden, and the
  glow-mushroom arsenal are all unchanged.

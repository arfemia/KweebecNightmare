Kweebec Nightmare for Hytale's Update 7. Install it when your server moves to Update 7, together with Ziggfreed's CommonLib 2.3.0; a server still on Update 6 stays on 1.2.1.

- **Made for Update 7.** The server no longer flags Kweebec Nightmare at startup as made for an older version of the game. It needs Ziggfreed's CommonLib 2.3.0 or newer, CommonLib's Update 7 release, and Perfect Utils.
- **The Lunger still lunges at full speed.** Update 7 changed how a charging creature gets up to speed, which would have made the Lunger ease into each lunge and slow down before the end of it. It still bursts at you at full speed and stops dead.
- **A quiet server log when a round starts.** The grove's title card is set up the way Update 7 expects, so starting a round no longer writes a warning to your server log. It looks the same as before.

Built on Update 7 against Ziggfreed Common 2.5.0 (the compile pin). The manifest drops `narwhals:Perfect Utils` and moves the `Ziggfreed:ZiggfreedCommon` floor from `>=2.3.0` to `>=2.5.0`, the library that ships `StunControl` and `AggroControl` (R364: the floor moves for newer library API). Perfect Utils is no longer a dependency of any kind (R740).

- **The Moonbloom stun is CommonLib's `StunControl`.** `KweebecDamageSystem.stunMob` and `stunPlayer` call `StunControl.isStunned` and `StunControl.stun` through the damage system's command buffer, in seconds (`RuleSet.stunDurationMs() / 1000`), attributed to the thrower. The library's `Zig_Stunned` effect has the vanilla `Stun` as its `Parent`, so the separate vanilla `Stun` visual (`applyStunVisual`, `STUN_VISUAL_EFFECT`) is gone: one effect carries the look, the movement hold and the player input lock, and the call also cancels the target's running chains and holds a creature's attacks. A thrower is credited `mobsStunned` only when the stun landed.
- **The hunters' taunt is CommonLib's `AggroControl`.** `AiHunterController.tick` opens `AggroControl.taunt(store, survivor, 2.5 s, 256)` where it called `AggroAPI.taunt`, and `clearTaunt` ends it with `isTaunting` and `clear`. The window lives in the world's store, never on the survivor, so the old guard against removing a component from a dead survivor's archetype is no longer needed; the "AggroAPI unavailable" warning is gone with the API.
- **Build and setup.** `build.gradle` loses `perfectUtilsJar` and its `compileOnly`, `gradle.properties` loses `perfectUtilsVersion`, and `KweebecNightmarePlugin.setup` loses the `AggroAPI` and `StunMobAPI` probe. The workspace's `family.properties` drops `Developer-Utils` from `dep.kweebec-nightmare`, so a dev boot stages and loads this mod with no companion.

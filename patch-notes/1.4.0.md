Kweebec Nightmare no longer needs Perfect Utils. Ziggfreed's CommonLib is the only mod it needs beside it.

Built for Update 7, and needs Ziggfreed's CommonLib 2.5.0 or newer.

### Changes

- A thrown Moonbloom still freezes a hunter, cuts off its swing and keeps it from attacking until it wakes, and in Clash it still stuns an enemy player. The stun now comes from CommonLib.
- Hunters still turn on the survivor the night picks for them, such as the one nearest the gate when it alerts. That pull now comes from CommonLib too.

### For server owners

- Remove Perfect Utils from your `Mods/` folder if nothing else on your server uses it. Kweebec Nightmare loads without it.

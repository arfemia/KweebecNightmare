Kweebec Nightmare no longer needs Perfect Utils. Ziggfreed's CommonLib is the only mod it needs beside it, and it is ready for MMO Skill Tree 2.0.

Built for Update 7, and needs Ziggfreed's CommonLib 3.0.0 or newer.

## Changes

- A thrown Moonbloom still freezes a hunter, cuts off its swing and keeps it from attacking until it wakes. The stun now comes from CommonLib.
- Hunters still turn on the survivor the night picks for them, such as the one nearest the gate when it alerts. That pull now comes from CommonLib too.
- With MMO Skill Tree 2.0, the Emberbloom, the Gustbloom and the Moonbloom keep training Artillery with every burst.

## For server owners

- Remove Perfect Utils from your `Mods/` folder if nothing else on your server uses it. Kweebec Nightmare loads without it.
- Moving to MMO Skill Tree 2.0? Update Kweebec Nightmare with it. The Emberbloom's, Gustbloom's and Moonbloom's Artillery XP ships with this version, so an older one beside MMO Skill Tree 2.0 pays no Artillery XP for their bursts.
